# Contributing to OpDoc AI Auto Organizer

Thank you for contributing. You may open issues and pull requests in any language.

## Issues

Search existing issues before opening a new one.

- For a bug, include your OpDoc and Obsidian versions, operating system, steps to reproduce, expected behavior, and actual behavior.
- For a feature request, describe the problem you want to solve and the result you expect.
- Remove API keys, private note content, and other sensitive information from logs and screenshots.

Use the [issue templates](https://github.com/rklpoi5678/OpDoc-AI-Auto-Organizer/issues/new/choose) to get started.

## Pull requests

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Make one focused change and update the documentation when needed.
4. Run `npm run lint` and `npm run build`.
5. Open a pull request that explains the change, links related issues, and lists the checks you ran.

Small fixes are welcome. For a large behavior change, open an issue first so the approach can be discussed before implementation.
